# M1 — Sellable Frontend Demo

## Goal
Produce a polished client-facing high-school public website demo with reusable, backend-ready frontend architecture.

## Exit criteria
- approved visual/design system;
- complete core public pages and shared shell;
- responsive behavior verified across target widths;
- notices/teachers/routine/results/gallery/admission/contact experiences coherent;
- accessibility/performance review completed;
- independent design critique addressed;
- clean handoff path for Frappe data integration;
- canonical state and verification records complete.
