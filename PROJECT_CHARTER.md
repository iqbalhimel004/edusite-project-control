# EduSite Project Charter

## Mission
Build a reusable, commercial, white-label platform for Bangladeshi secondary/high schools consisting of:
1. a visually premium, highly customizable public school website frontend; and
2. a stable school-management backend built on proven systems rather than a fully vibe-coded backend.

Working commercial brand: **EduSite / EduSite Solutions**  
Development demo school: **Sunrise Model High School**

## Core product principle
**Frontend flexible and visually premium; backend stable, boring and reliable.**

## Target market
Secondary/high schools in Bangladesh, initially Class VI–X / SSC-level institutions.

## Commercial direction
- Entry marketing promise may remain **"from BDT 5,000/year"** for a basic website tier.
- Full school-management functionality belongs to higher-priced tiers.
- SMS usage and payment transaction charges should not be silently absorbed into an unlimited low-cost package.

## Product layers
### Public Website
Premium, responsive, white-label frontend, suitable for vibe coding and visual variation without coupling presentation to backend internals.

### School Management Backend
Planned baseline:
- Frappe Framework
- ERPNext
- Frappe Education
- EduSite BD custom Frappe app for Bangladesh-specific requirements

## Scope discipline
Do not build a complete ERP from scratch. Reuse mature backend capabilities and customize only where necessary.

## Current priority
Create a strong sellable frontend demo first while Arena Fable 5.1 access is available; backend integration follows after the frontend foundation is proven.
