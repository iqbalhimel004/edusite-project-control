# EduSite Project Control

Canonical project-control repository for **EduSite**, a reusable white-label high-school website and school-management platform for Bangladesh.

## Start here
Read [`START_HERE.md`](START_HERE.md) first. For the current machine-readable state, see [`PROJECT_STATE.yaml`](PROJECT_STATE.yaml) and [`CURRENT_STATE.md`](CURRENT_STATE.md).

## Authority
This repository stores architecture, ADRs, roadmap, tasks, verification state, important prompts and agent-execution policy. Its latest **verified/merged state** overrides chat memory or agent assumptions.

Product code belongs in separate repositories when created. Existing/legacy repositories are off-limits unless the project owner explicitly authorizes a specific repository and action.
