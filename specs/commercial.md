# Commercial Specification

## Entry offer
Marketing may use **"from BDT 5,000/year"** for a basic website tier.

## Suggested tier logic
### Basic Website
Public website, notices, teachers, gallery, routine/result publication UI as supported, domain/hosting package as commercially viable.

### School Management
Adds core student/teacher/admission/attendance/results/admin workflows.

### Advanced
Adds portals, richer fee/SMS/reporting/payment integrations and other operational modules.

Exact pricing is not yet frozen.

## Variable usage costs
SMS messages and payment transaction fees should be treated separately or explicitly capped rather than hidden inside an unlimited low-cost annual package.
