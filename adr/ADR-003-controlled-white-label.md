# ADR-003 — Controlled White-label Customization
Status: Accepted

## Decision
Use one reusable frontend component system with configuration for identity, theme tokens, imagery, content, homepage section visibility/order and a small set of supported variants.

Do not build a free-form drag-and-drop page builder in the initial product.

## Rationale
This gives schools meaningful visual differentiation without creating separate codebases or unbounded layout complexity.
