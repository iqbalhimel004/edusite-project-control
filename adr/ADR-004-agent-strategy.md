# ADR-004 — Agent Strategy
Status: Accepted

## Decision
- ChatGPT: Technical Lead / planner / reviewer / release gatekeeper.
- Codex: default implementation engine.
- Fable 5.1: premium UI/UX and frontend specialist while available.
- Hyperagent: complex specialist / independent review / difficult debugging.
- Antigravity: large autonomous engineering or specialist work when advantageous.
- Zed.dev: workspace/IDE; AI used selectively.
- Notion: optional supplementary human dashboard, never a competing source of truth.

Default collaboration pattern is one primary implementer plus one reviewer only when justified.
